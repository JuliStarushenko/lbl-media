Privacy Policy

Who uses it. Layer by Layer Daily Tools is a private tool used only by the owner of the YouTube channel Layer by Layer Daily, with the owner's own Google account. It is not offered to other users.

What it accesses, with the owner's permission, through the official YouTube API Services:

  • uploading the channel's own videos and setting their publish time (youtube.upload);
  • reading the channel's own videos and comments, and posting replies as the channel (youtube.force-ssl);
  • reading the channel's own YouTube Analytics reports, such as views and engaged views (yt-analytics.readonly).

How the data is used and stored. The data is used only to plan and publish the channel's own content. Statistics and the access token are stored privately on the owner's computer. Nothing is sold, shared with third parties, or used for advertising.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data is deleted when the owner deletes it from their computer.

This tool uses YouTube API Services: YouTube Terms of Service, Google Privacy Policy.
